# Spec Changes

No spec-level requirement changes are introduced by this migration.

This is an infrastructure-only change: the build tool (Next.js → Vite) and routing mechanism (App Router → React Router) are being replaced, but all user-facing capabilities (local profile editing, set creation, photo ingest, publish export, published profile viewing) retain their existing behavioral requirements.

All existing specs in `openspec/specs/` remain valid without modification.
